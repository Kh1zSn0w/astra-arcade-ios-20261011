# ASTRA: LAST LIGHT SQUADRON

Original pixel-art portrait arcade shoot-'em-up for iPhone. Built with native SpriteKit, SwiftUI and AVFoundation.

## Play
Drag anywhere in the lower playfield to fly (ship stays above your finger). Cannons auto-fire. Tap BOMB to clear hostile bullets and damage enemies. Dodge tight spreads, grab power/repair/shield/bomb supplies, build a chain multiplier and survive the dreadnought encountered roughly every minute. Pause from top-right.

## Build
Uses XcodeGen and the iOS SDK. Run the free `macos-15` GitHub Actions workflow. The resulting unsigned IPA is built for signing with Sideloadly using the owner's Apple ID.

## License and data
All sprite art, effects, and music are generated by `make_assets.py`, with no third-party proprietary content. No accounts, ads, analytics, network access, remote assets, credentials, or gameplay data uploads. Local highest score and settings are stored using UserDefaults.

Native launch and physical-device gameplay performance still require verification on an actual iPhone.
